# Parte 2 – Cálculo do custo de importação

## Como rodar
Requer Python 3.8+ (somente biblioteca padrão, nada para instalar).

```bash
python calculo_importacao.py
```
No VS Code: abra a pasta, abra `calculo_importacao.py` e clique em *Run Python File*.
Os dados do enunciado estão no topo do arquivo (`MPS`, `ESTRUTURA`, `VENDAS`); basta editá-los para outros cenários.
O programa imprime o resultado por produto e a conciliação, e termina com `assert`s que falham se algo não fechar.
